# 网页（0.2.0）

网页包为 `@apexo/sdk`（`0.2.0`），源码位于 [`web/src/`](../web/src/)。演示位于 [`web/demo/`](../web/demo/)，由 [`node server.js`](../web/demo/server.js) 提供服务，默认监听 `http://127.0.0.1:4173/`。响应带 `Cross-Origin-Opener-Policy: same-origin` 与 `Cross-Origin-Embedder-Policy: require-corp`，满足 LiteRT-LM 多线程 WebAssembly 的跨源隔离要求。

## 打包器接入与静态资源复制（`copy-runtime.mjs`）

在 Vite、Webpack 或任意静态服务器中接入 `@apexo/sdk` 时，无需依赖演示服务器的 `/vendor/` 目录。包内自带 `apexo-copy-runtime`（[`web/scripts/copy-runtime.mjs`](../web/scripts/copy-runtime.mjs)），可将 `sherpa-onnx` 与 `@litert-lm/core` 的 Wasm/JS 运行时一键复制到宿主静态目录（包括子路径部署）：

```bash
node ./node_modules/@apexo/sdk/scripts/copy-runtime.mjs ./public/assets/apexo
```

复制后的目录结构与 `createSession` 配置对应如下：

- `./public/assets/apexo/sherpa/` → `sherpaUrl: "/assets/apexo/sherpa/"`
- `./public/assets/apexo/litert/` → `litertWasmUrl: "/assets/apexo/litert/"`
- 若宿主不使用打包器解析裸模块说明符 `@litert-lm/core` 和 `@litertjs/wasm-utils`，可在页面中添加 `importmap` 指向复制出的 `/assets/apexo/litert/dist/index.js` 和 `/assets/apexo/wasm-utils/dist/index.js`。

完整接入示例见 [`web/examples/vite/`](../web/examples/vite/)。

## 标准异步调用流

### 1. 实时录音、阶段摘要与停止后完整总结

```js
import { createSession } from "@apexo/sdk";

const session = createSession({
  asrModelPath: "/models/asr-zh",
  summaryModelPath: "/models/gemma-4-E2B-it-gpu.litertlm",
  sherpaUrl: "/assets/apexo/sherpa/",
  litertWasmUrl: "/assets/apexo/litert/",
  onTranscript(event) {
    console.log(event.isFinal ? "[FINAL]" : "[INTERIM]", event.text, event.startMs, event.endMs);
  },
});

await session.loadRecognizer();

// 录音进行中持续推入 PCM（支持 48000 Hz 等任意采样率，内部自动流式重采样为 16000 Hz）
session.pushPcm(pcmFloat32Chunk, 48000);

// 录音中途生成滚动阶段摘要（不阻塞后续 pushPcm，不将未完成 interim 强行定稿）
const stageSummary = await session.summarizeNew();

// 用户点击停止：先停止采集并送完最后一块音频，再等待 endSegment() 刷出识别器尾帧
await session.endSegment();
const fullTranscript = session.fullTranscript;
const finalSummary = await session.summarize();
```

### 2. 纯文本总结（无需加载 ASR 或麦克风）

```js
const textSession = createSession({
  summaryModelPath: "/models/gemma-4-E2B-it-gpu.litertlm",
  litertWasmUrl: "/assets/apexo/litert/",
});

const summary = await textSession.summarize("会议记录：原定周五发布，经压测评估决定取消周五计划，最终改到下周三下午发布。");
await textSession.dispose();
```

## 演示页按钮说明（`web/demo/`）

- **开始录音**：调用 `session.reset()` 清空上一段，打开麦克风并通过 AudioWorklet 采集单声道 PCM 送入 `session.pushPcm`。
- **结束**：先切断采集入口、排空已采集的最后一块音频，再 `await session.endSegment()` 通过 `InputFinished` 刷出尾词并冻结本段。
- **阶段摘要**：在录音中途或结束后调用 `await session.summarizeNew()`，对上次摘要之后新增的定稿文字生成阶段摘要，录音中途点击不会停止麦克风采集。
- **总结**：若仍在录音则先执行完整结束流程（`finishRecording()`），再调用 `await session.summarize()` 生成跨块汇总后的完整会议总结。
- **回听刚才这一段**：回放最近一段采集的原始 PCM。
- **下载 Gemma 4 E2B**：下载 `gemma-4-E2B-it-gpu.litertlm` 并通过 `session.setSummaryModel(chunks)` 注入内存模型数据。
- **启用浏览器自带识别（默认关闭）**：当本地 `asr-model/` 四个模型文件缺失或加载失败时，页面如实显示缺失/失败原因，**默认不会静默回退到浏览器云端识别**；仅当用户主动勾选该复选框时才启用 `SpeechRecognition`，并明确提示音频可能发往云端服务。

## 模型探测说明

SDK 使用标准 `HEAD` 请求探测模型文件是否存在：

- 返回 `200`（且 `Content-Type` 不是 `text/html`，防止 SPA fallback 误判）视为存在。
- 返回 `405` 或 `501`（部分静态文件服务器不支持 `HEAD`）时保留给实际 `GET` 加载阶段验证。
- 返回 `404` 视为缺失，无需服务端实现任何私有请求头。
